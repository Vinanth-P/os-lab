-----------
There are N philosophers sitting around a circular table
Between each pair of philosophers, there is one fork
Each philosopher needs two forks (left + right) to eat

Philosophers alternate between:

Thinking 
Eating 

*problem:
If all philosophers pick up one fork at the same time, then:

Everyone is holding one fork
No one can get the second fork
Deadlock occurs

*Deadlock happens if:

All philosophers pick left fork first
All wait for right fork
No one releases → system stuck

*Solutions to Avoid Deadlock
1. Resource Ordering
Pick forks in a fixed order (e.g., lower-numbered first)
2. Limit Philosophers
Allow at most N−1 philosophers to sit at table
3. Asymmetric Solution
Odd philosophers pick left first
Even philosophers pick right first
