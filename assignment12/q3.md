# 🔷 🔍 Algorithm-wise Analysis

## 🔹 1. First Fit

* Allocates **first suitable block**
* ✔ Very fast (no full search)
* ❌ Creates many **small fragments at beginning**

👉 Best when:

* Speed is priority
* Memory is not highly fragmented initially

---

## 🔹 2. Next Fit

* Starts search from **last allocated position**
* ✔ Slightly faster than First Fit
* ✔ Reduces clustering at beginning

👉 Best when:

* Memory usage is continuous
* Avoiding repeated scanning of same blocks

---

## 🔹 3. Best Fit

* Chooses **smallest possible block**
* ✔ Minimizes wasted space
* ✔ Highest memory utilization

❌ But:

* Creates **tiny unusable fragments**
* Slower (full search required)

👉 Best when:

* Memory is limited
* Need to maximize utilization

---

## 🔹 4. Worst Fit

* Chooses **largest available block**
* ✔ Avoids very small fragments initially

❌ But:

* Wastes large blocks quickly
* Poor utilization over time

👉 Best when:

* Large processes dominate
* Want to delay fragmentation
